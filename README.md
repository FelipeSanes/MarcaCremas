# Aura Botánica

Tienda online de productos de higiene y cuidado personal. Catálogo navegable,
página por producto y pedido que se envía por WhatsApp (sin pagos online).

```bash
npm install
npm run dev     # http://localhost:3000
```

Ver `CLAUDE.md` (guía técnica) y `reglas.md` (formato de productos e imágenes).
